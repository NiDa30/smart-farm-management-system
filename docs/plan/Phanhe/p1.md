# PHÂN HỆ 1 — HỆ THỐNG & PHÂN QUYỀN

## Mục tiêu

Quản lý tài khoản, vai trò, quyền truy cập, cấu hình trang trại và các thông tin nền tảng dùng chung cho toàn hệ thống.

## Chức năng chính

### 1. Quản lý người dùng

- Tạo tài khoản
- Chỉnh sửa thông tin
- Khóa / mở khóa
- Gán vai trò
- Gán phạm vi quản lý

### 2. Vai trò và phân quyền

Có thể hỗ trợ các vai trò:

- Admin
- Chủ trang trại
- Quản lý
- Kỹ thuật viên
- Nhân viên sản xuất
- Nhân viên kho
- Nhân viên kinh doanh
- Người chỉ xem

Phân quyền theo:

- Phân hệ
- Chức năng
- Trang trại
- Khu vực
- Dữ liệu

### 3. Cấu hình hệ thống

- Trang trại
- Đơn vị tính
- Danh mục dùng chung
- Cấu hình thông báo
- Cấu hình quy trình
- Các tham số vận hành

### 4. Audit Log

Theo dõi:

- Ai thực hiện
- Thao tác gì
- Thời gian
- Dữ liệu trước / sau thay đổi
- Đối tượng bị tác động
